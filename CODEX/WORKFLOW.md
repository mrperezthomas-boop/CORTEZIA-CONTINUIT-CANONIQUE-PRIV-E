## Two-repository model
1. This repository = continuity/canon/context.
2. The actual Cortezia website repository/worktree = application code and runtime.

Never confuse them.

## Start of a Codex mission
1. Read root AGENTS.md.
2. Read 00_START_HERE/00_READ_ME_FIRST.md.
3. Load only the targeted canon/current/evidence files needed.
4. Inspect the actual local website/worktree when the task depends on runtime truth.
5. Do not infer current runtime from this continuity repo alone.
6. Before website mutation, follow the approval gate from the canon.
7. Write code only in the actual website worktree after authorization.
8. Write reports/handoffs back to the continuity system, not into the website repo unless explicitly required.
